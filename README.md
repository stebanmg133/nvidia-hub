# NVIDIA Atlas

Sitio interactivo en español sobre el ecosistema NVIDIA, hecho con Java, Spring Boot, Tailwind CSS y JavaScript.

## Ejecutar localmente

Requisitos: Java 21 y Maven.

```bash
mvn spring-boot:run
```

Abre <http://localhost:8080>.

## Funciones

- Noticias del NVIDIA Newsroom y NVIDIA Blog mediante RSS.
- Cotización indicativa de NVDA.
- PC Builder con perfiles Gaming, Creación e IA local, coste estimado y comprobaciones básicas de compatibilidad.
- Secciones interactivas de plataformas, industrias, medios y recursos para desarrolladores.

Las cotizaciones, precios de componentes y puntuaciones son informativos; no son asesoramiento financiero ni precios de tienda. Las imágenes y Tailwind CDN requieren conexión a internet.
